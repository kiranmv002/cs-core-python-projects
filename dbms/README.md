# 🗄️ Database Management Systems Projects

This folder contains DBMS-related simulations implemented in Python to understand core database concepts practically.

These projects focus on basic database operations and file-based data storage.

---

## ✅ Completed Projects

### 1. Mini File-Based Database System

Implemented a simple database system using text file storage.

### Implemented Operations:

- Insert Record  
- View All Records  
- Search Record by ID  
- Delete Record  

### Storage Used

- Text file (`database.txt`)  

### Concepts Practiced

- Basic DBMS operations (Insert, Select, Delete)  
- File handling  
- Record searching and filtering  
- Data modification logic  
- Persistent data storage
